# H743 FPV Drone Project

Custom-built 5-inch FPV quadcopter featuring an H743 flight controller, 60A 4-in-1 ESC, custom Betaflight configuration, flight tuning, and performance testing.

## Project Overview

This project involved component selection, hardware assembly, flight controller configuration, tuning, troubleshooting, and flight testing of a custom FPV drone platform.

## Key Features

- H743 Flight Controller
- 60A 4-in-1 ESC
- Betaflight Firmware
- ELRS Control Link
- Blackbox Logging
- Flight Performance Tuning
